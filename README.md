# Interactive Spatial Econometrics Dashboard

This project presents an interactive R Shiny dashboard for exploring spatial patterns and estimating spatial econometric models.

The dashboard allows users to interact with the data, visualize geographic patterns, and investigate spatial dependence across regions. It provides tools to estimate and compare different spatial econometric specifications and evaluate their performance using relevant statistical criteria.

A key feature of the application is the ability to **compare alternative spatial econometric models and identify the best-performing specification**, supporting a more robust analysis of spatial relationships and regional differences.

## Interactive Dashboard

📊 **Launch the dashboard:**  https://ktrelles.shinyapps.io/Spatial_Data_Project/

## Main Features

* Interactive exploration and visualization of spatial data.
* Dynamic maps and filters for geographic analysis.
* Detection and analysis of spatial dependence.
* Estimation of alternative spatial econometric models.
* Comparison of model specifications using statistical criteria.
* Selection of the best-performing spatial econometric model.
* Interactive visualization and interpretation of estimation results.
